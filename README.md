# Synapse Forge

A mobile-first, browser-native cognitive training game built with vanilla HTML, CSS, and JavaScript.

## Run locally

```bash
python3 -m http.server 8080
```

Open `http://localhost:8080` in a browser.

## Included gameplay

- Mixed Quick, Standard, Deep, and single-mode Forge sessions.
- Rapid Association, The Pause (including delayed responses and temptation cues), Working Memory, Flex Forge, Recovery Forge, knowledge puzzles, Lexicon Builder, and Constrained Story.
- Local persistence for scores, settings, missions, achievements, lexicon mastery, progression records, and training preference.
- Keyboard-friendly typed responses and choice controls, plus reduced motion, high contrast, large text, timing, haptics, sound, and one-handed settings.
